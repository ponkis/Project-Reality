# Project Reality agent instructions

## Runtime and visual testing

- Do not launch, control, or interact with the game executable.
- Do not perform in-game visual checks, input automation, screenshot capture, or runtime UI inspection.
- Restrict verification to builds, static checks, packaged-asset validation, and other non-interactive audits.
- The user performs all runtime and visual game testing. Report when changes are compiled and staged, then leave visual confirmation to the user.
